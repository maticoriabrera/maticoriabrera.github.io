# Performance 7 Digital — prototipo de sitio institucional

Esta entrega es un prototipo estático en español para visualizar el planteamiento comercial de Performance 7 Digital.

## Estructura

- `index.html`: Home institucional. Soluciones por sector, capacidades transversales, metodología y contacto.
- `nutricion/index.html`: digitalización de planes alimentarios.
- `ortopedia/index.html`: catálogos de productos ortopédicos.
- `salud/index.html`: catálogo y presentaciones comerciales de Dr. Ehrlichs.
- `menues/index.html`: menús gastronómicos.
- `assets/css/styles.css`: estilos globales y adaptaciones responsive.
- `assets/js/main.js`: menú móvil y accesibilidad básica.
- `assets/img/`: imágenes SVG originales y conceptuales, **no** capturas de los sitios originales.

## Publicación en GitHub Pages

1. Extraé el ZIP.
2. Subí **el contenido de la carpeta** a la raíz del repositorio que publiques con GitHub Pages. El archivo `index.html` debe quedar en la raíz publicada.
3. En GitHub, configurá **Settings → Pages → Deploy from a branch** y seleccioná la rama / carpeta que corresponda al repositorio.
4. La navegación utiliza rutas relativas, por lo que funciona tanto bajo `usuario.github.io/repositorio/` como bajo un dominio propio.

Puede abrirse `index.html` localmente para una revisión rápida; para pruebas más completas, también puede usarse un servidor HTTP local.

## Contacto

Se utiliza `performance7digital@gmail.com`, dirección de contacto publicada en la página existente de Performance 7 Gastronomia. Los botones de contacto abren el programa de correo del visitante (`mailto:`). **No se incluye un formulario con backend ni se almacenan mensajes**.

## Alcance y limitaciones

- Sitio de prueba, no una integración de los desarrollos externos.
- La estética «P7» y las ilustraciones SVG son recursos provisionales originales para esta demo, no una sustitución obligatoria del logotipo institucional.
- Las referencias a Amazon, Instagram y Mercado Libre son **simulaciones de presentación**, no integraciones, ventas activas, perfiles oficiales ni publicaciones reales.
- No se incluyen métricas de ventas, resultados o valoraciones no verificadas.
- No se implementó un CMS, panel de administración, carrito, sistema de pago o integración comercial.
- Antes de lanzar en producción: revisar autorización de marcas y demostraciones, política de privacidad y textos legales correspondientes, además del posicionamiento de idiomas.
